Privacy Policy

Last updated: November 20, 2026

This policy describes how youtube-robotu ("the app"), operated by the owner of the Respawn Report YouTube channel, handles information when it uses Google and YouTube services.

1. Who uses the app

The app is a private tool used only by the channel owner. It is not offered to the public.

2. Data the app accesses

With the owner's permission, the app uses the YouTube Data API to (a) upload videos to the owner's own channel and (b) read the owner's own channel name to confirm the connection. The app requests only the youtube.upload and youtube.readonly scopes.

3. How data is stored

The OAuth access token is stored only on the owner's own computer. It is not sent to any third party, not sold and not shared. No data about other YouTube users is collected or stored.

4. Use of Google user data

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also complies with the YouTube Terms of Service and the Google Privacy Policy.

5. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the token file from the owner's computer also removes all stored access.
